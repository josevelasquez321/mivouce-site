# MiuVoice · sitio web

Sitio estático de MiuVoice, traducción de voz y pantalla en tiempo real.

- `index.html`, `styles.css`, `script.js`: la página.
- `i18n.js`: textos en español, inglés, francés, portugués, alemán e italiano (selector arriba a la derecha).
- `assets/img`: ilustraciones (WebP optimizado), logo, favicon e imagen para redes (`og.jpg`).
- `assets/icons`: iconos recortados del set de iconos.
- `assets/miu`: poses de Miu renderizadas desde los SVG de la app.

Se publica con GitHub Pages desde la rama `main` (carpeta raíz).
